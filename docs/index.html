1 这是啥：往实习生兜里塞张小抄

你让 AI 科普一个东西，它甩给你三千字，术语一个追一个，读到第三屏你就把标签页关了。这不是模型笨，是没人告诉它：你的读者坐不住。

这种“写给 agent 看的说明书”有个正式名字——Agent Skills（技能包）：一个装着规则和模板的文件夹，agent 动笔前会先翻一遍。

把你的 agent 想成一个手特别快的实习生：打字飞快、爱堆术语、不写大纲。write4adhd 干的事只有一件：往它兜里塞一张写作小抄。从此它每次动笔前，都会先摸一下兜。

“小抄上到底写了啥？”——五条硬规矩：一个土味比喻贯穿全文、段落不许超过 4 行、每章末尾一句加粗的收束句、术语先说人话再给学名、图一律手绘 Canvas 还得会动。

说白了：不是换了个更聪明的 AI，是给同一个 AI 换了一套“为没耐心的人写作”的规矩。

1 What it is: a cheat-sheet for your intern

You ask an AI to explain something. It hands back three thousand words, jargon stacked on jargon, and by the third screen you've closed the tab. That's not the model being dumb — nobody told it that your reader won't sit still.

This kind of "instruction manual written for an agent" has a proper name — Agent Skills: a folder of rules and templates the agent reads before it starts writing.

Picture your agent as a very fast intern: types like lightning, loves jargon, never outlines. All write4adhd does is slip a writing cheat-sheet into its pocket. From then on, it checks that pocket before every draft.

"So what's on the cheat-sheet?" — Five hard rules: one homespun metaphor running the whole piece, no paragraph longer than 4 lines, a bolded closing line for every chapter, plain words before any term, and hand-drawn Canvas diagrams that actually move.

Bottom line: it isn't a smarter AI — it's the same AI on a "write for the impatient" rulebook.

2 装上之后，文章长成这样

小抄进兜了，那效果呢？同一只手快的实习生，交出来的东西完全两样：

  • 祛魅：读完你能用自己的话说出这东西是什么、难在哪，而不是“好像很厉害但没懂”；
  • 一个土味比喻贯穿全文：整篇只需要记住一件事；
  • 每章一句加粗的收束句：随时停下，随时接得上；
  • 段落不超过 4 行：段落墙在这里是违法的；
  • 手绘 Canvas 示意图 + 分步动画：默认播放、滚出屏幕自动暂停，还给你暂停 / 单步 / 重播三个按钮；
  • 产出即成品：单页自包含 HTML、分章多页书站、或 Markdown——亮暗主题、离线可用、零外部依赖。

2 What your docs look like afterwards

The cheat-sheet is in the pocket — so what changes? Same fast intern, completely different deliverable:

  • Demystified: you finish able to say in your own words what the thing is and where the hard part was, instead of "sounds impressive, still lost";
  • One homespun metaphor, end to end: exactly one thing to remember;
  • A bolded closing line for every chapter: stop anywhere, pick it back up anywhere;
  • No paragraph longer than 4 lines: walls of text are illegal here;
  • Hand-drawn Canvas diagrams with step animations: they autoplay, pause when you scroll away, and hand you pause / step / replay buttons;
  • The output is a finished artifact: a single self-contained HTML page, a multi-page book site, or Markdown — light and dark themes, offline, zero external dependencies.

“动画会不会又变成新的注意力陷阱？”——不会。动画默认播放，但你一滚走它就自己停；想慢慢看就点“下一步”，一帧一帧喂给你。控制权在你手上，不在页面上。

关键不是把文章写短，是把“能读完”当成硬指标。

"Don't animations just become a new attention trap?" — No. They autoplay, but pause themselves the moment you scroll away; want to take it slow, hit "step" and it feeds you one frame at a time. The controls belong to you, not to the page.

The trick isn't writing less — it's treating "readable to the end" as a hard requirement.

3 三步用起来

回忆一下：skill 就是个文件夹，没有安装程序。所以“用起来”一共三步：

① 拷一个 skill 目录→ ② 跟 agent 说人话→ ③ 拿到能直接打开的 HTML

每个 skill 都有中英两个版本：规则和模板完全一样，区别只在产出文档的语言。两者同名，装一个就够——要写中文文档就拷 skills-cn/ 的，要写英文就拷 skills-en/ 的。

# 项目级：只有当前项目能用（英文版把 skills-cn 换成 skills-en）
cp -r skills-cn/write4adhd-book <你的项目>/.agents/skills/

# 用户级：所有项目都能用
cp -r skills-cn/write4adhd-book ~/.agents/skills/

然后在任何支持 Agent Skills 的 agent（比如 pi）里直接点名：

/skill:write4adhd-book 写一篇《什么是 Docker》

懒得记命令？说人话也行：“用祛魅体给我科普一下 XXX”、“给这个项目写份零基础入门文档”。

“为什么是 cp 而不是安装？”——因为 skill 就是一堆纯文本文件：没有依赖、不联网、不动你的 shell 配置。拷进去就生效，删掉就没了，搬家就再拷一次。

装一个 skill 的成本，和拷一个文件夹一模一样。

3 Three steps to use it

Remember: a skill is just a folder — there's no installer. So "getting started" is three steps:

① Copy one skill folder→ ② Ask in plain words→ ③ Open the HTML it hands back

Every skill ships in two language variants: identical rules and templates, the only difference is the language it writes in. They share a name, so install just one — skills-cn/ writes Chinese, skills-en/ writes English.

# Project level: this project only (use skills-cn for the Chinese skill)
cp -r skills-en/write4adhd-book <your-project>/.agents/skills/

# User level: every project
cp -r skills-en/write4adhd-book ~/.agents/skills/

Then, in any agent that supports Agent Skills (such as pi), call it by name:

/skill:write4adhd-book write a plain-English primer on Docker

Can't be bothered with commands? Just talk to it: "explain XXX like I've never heard of it", or "write a zero-background intro to this project".

"Why a cp instead of an install?" — Because a skill is a pile of plain-text files: no dependencies, no network calls, nothing written into your shell config. Copy it in and it works; delete it and it's gone; moving machines means copying it again.

Installing a skill costs exactly as much as copying a folder.
